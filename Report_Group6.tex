\section{Introduction}

A monkey typing individual keys on a keyboard at random will almost certainly, given enough time, type any finite combination of the available keyboard alphabet. For example, this could be a piece of historical literature or even a million-character long string of letters produced by a Python-coded random text generator. However, over a period samplable in a lifetime, the probability of these outcomes is minute. This is the infinite monkey theorem.

The objective of our coursework is to investigate creationist ideas that use this theorem to suggest that the odds of biological evolution for all life forms are so small, that there \textbf{must} be a divine creator.
We aim to demonstrate that the process that drives evolutionary systems (i.e., random variation combined with non-random cumulative selection) is different to pure chance. We will do this by mirroring some experiments carried out in the Richard Dawkins’ Weasel Program.

\section{Overview}

Our goal throughout these experiments is to recreate the Dylan Thomas quote, “he who seeks rest finds boredom. he who seeks work finds rest.”, using random text generation. We fix the randomly generated to string to be exactly 62 characters long and we limit the available alphabet to 28 characters: a-z, spaces, and full stops. This gives the probability for a randomly generated string to match the target string to be 1 in \(5.294 \times 10^{89}\).


\section{Methodology}

\subsection{Pure random search}

A function will return a randomly generated 62-character string \(S\) over the 28-character alphabet. \(S\) is then evaluated by a function that scores it out of 62 based on the number of positions whose characters match those of the target string \(T\). 

We will analyse the distribution of scores across many iterations. This is our purely random ‘base’ code.

\subsection{Simulated evolution and convergence analysis}

An offspring string \(S'\) is generated, a clone of \(S\). Then, a randomly selected character of \(S'\) is replaced by another randomly generated character from our alphabet. The scoring function evaluates both strings and if the score of \(S'\) is greater than that of \(S\), \(S'\) takes the place of \(S\). This process loops until the score of S is equal to 62 and the target string has been achieved. 

We will analyse the distribution of iterations of the loop required for \(T\) to be produced.

\subsection{Further Exploration}

To deepen our understanding of the model, we investigate how a range of parameter variations affect its efficiency. These include string length, mutation rate, and memory based mutation. 

Similarly, convergence analysis of each variation will be carried out and compared to each other.

\section{Inserting Code}

To add snippets of code to a document, you should use the \texttt{lstlisting} environment, specifying within the command that the Python programming language is being used. Note that in this environment the text is presented exactly as it has been typed in; it is therefore best to paste your final code directly from your Python editor. Here is an example:
   
\begin{lstlisting}[language = python, frame=single]
total = 0.0
i = 0

while i < 10:
	x = float(input("Enter number >> "))
	total += x
	i += 1

print("Average = " + str(total / float(i)))
\end{lstlisting}

You can also write pieces of code in-line using the \verb|\py| command. For example, a list of 100 zeros can be declared by the command \py{X = [0 for i in range(100)]}

Output from a program can also be specified using the \texttt{lstlisting} environment. In this case we do not require syntax highlighting, so there is no need to specify a programming language in \texttt{lstlisting} command in \LaTeX. Here is some example output from the above program.

\begin{lstlisting}[frame=single]
Enter number >> 1
Enter number >> 2
Enter number >> 3
Enter number >> 4
Enter number >> 5
Enter number >> 6
Enter number >> 7
Enter number >> 8
Enter number >> 9
Enter number >> 10
Average = 5.5
\end{lstlisting}
